# راهنمای گام‌به‌گام ساخت خودکار نقشه‌های رهیاب روی GitHub (رایگان و بدون نیاز به دستور خط فرمان)

با این روش، تمام نقشه‌های ایالت‌های آمریکا به‌صورت **کاملاً رایگان** روی سرورهای خود GitHub ساخته می‌شوند و مستقیماً داخل برنامه **رهیاب** قابل دانلود خواهند بود — بدون اینکه کامپیوتر شخصی شما درگیر شود!

---

## گام ۱: ایجاد مخزن (Repository) روی GitHub
1. وارد سایت [github.com](https://github.com) شوید و وارد حساب کاربری خود شوید (اگر حساب ندارید، یک حساب رایگان بسازید).
2. در AI Studio (همین محیطی که الان در آن هستید)، دکمه **Push to GitHub / Save to GitHub** را بزنید تا کل پروژه (شامل فایل workflow) مستقیماً به یک مخزن جدید در حساب GitHub شما منتقل شود.
3. **نکته بسیار مهم برای رایگان ماندن:** هنگام ساخت مخزن، حتماً گزینه **Public (عمومی)** را انتخاب کنید! روی مخازن عمومی (Public)، استفاده از GitHub Actions روی سرورهای استاندارد `ubuntu-latest` **کاملاً رایگان و نامحدود** است.

---

## گام ۲: دادن اجازه انتشار Release به GitHub Actions
1. وارد صفحه مخزن خود در GitHub شوید.
2. از نوار بالا روی تب **Settings** کلیک کنید.
3. از منوی سمت چپ، وارد **Actions** و سپس **General** شوید.
4. به پایین صفحه بروید تا به بخش **Workflow permissions** برسید.
5. گزینه **Read and write permissions** را انتخاب کنید و دکمه **Save** را بزنید.

---

## گام ۳: ساخت نقشه یک ایالت (مثلاً اورگن) یا چند ایالت با یک کلیک
1. در صفحه مخزن GitHub، روی تب **Actions** در نوار بالا کلیک کنید.
2. از ستون سمت چپ، روی **Build RahYab US Map Packs** کلیک کنید.
3. در سمت راست، روی دکمه **Run workflow** کلیک کنید.
4. در کادر **State code(s) to build**:
   - برای یک ایالت بنویسید: `or` یا `oregon` (اورگن)
   - برای چند ایالت با کاما جدا کنید: `or,wa,id` یا `oregon,washington,idaho`
   - برای همه ۵۰ ایالت + واشینگتن دی‌سی بنویسید: `all` *(ایالت‌های بزرگ کالیفرنیا، تگزاس، فلوریدا و نیویورک به‌طور خودکار به بخش‌های منطقه‌ای تقسیم می‌شوند)*
5. روی دکمه سبز **Run workflow** کلیک کنید و صبر کنید تا تیک سبز نمایش داده شود (برای یک ایالت معمولی حدود ۱۰ تا ۲۵ دقیقه زمان می‌برد).

---

## گام ۴: تنظیم رهیاب روی گوشی برای دانلود نقشه‌ها
1. برنامه **رهیاب (RahYab)** را روی گوشی باز کنید.
2. وارد تب **تنظیمات (Settings)** شوید.
3. در بخش **مخزن گیت‌هاب بسته‌های نقشه (GitHub Map Pack Source)**:
   - در کادر اول، **نام کاربری گیت‌هاب** خود را وارد کنید (مثلاً `ali-nemati`).
   - در کادر دوم، **نام مخزن** خود را وارد کنید (مثلاً `rahyab-maps`).
   - دکمه **ذخیره مخزن گیت‌هاب** را بزنید.
4. وارد تب **نقشه‌ها (Maps)** شوید و دکمه بروزرسانی (آیکون چرخش) در بالا را بزنید. ایالت‌هایی که ساخته‌اید با حجم و دکمه **دانلود** ظاهر می‌شوند!

---

## (اختیاری) فعال کردن بروزرسانی خودکار ماهانه
به‌طور پیش‌فرض، ساخت نقشه‌ها فقط زمانی انجام می‌شود که خودتان دکمه **Run workflow** را بزنید. اگر می‌خواهید اول هر ماه به‌صورت خودکار نقشه‌ها بروزرسانی شوند:
1. در GitHub فایل `.github/workflows/build-map-packs.yml` را باز کنید و آیکون مداد (Edit) را بزنید.
2. علامت `#` را از ابتدای دو خط `schedule:` و `- cron: "0 6 1 * *"` بردارید و ذخیره (Commit) کنید.
